## Usage Notes

### For Climate Dashboard:
1. **Background Videos**: The loop animations (especially the Landscape and Panda loops) would work great as subtle background animations for the dashboard
2. **Dotted Backgrounds**: Perfect for creating visual hierarchy and sections in the dashboard
3. **Feature Animations**: The "Infinitely Scalable", "Fully On-Chain AI", and "Seamless Composability" videos could be used to highlight different aspects of 0G's sustainability
4. **Icons and Logos**: Use for branding and partner sections

### Technical Considerations:
- Most videos are available in both MP4 and WebM formats for browser compatibility
- Images are available in multiple resolutions for responsive design
- AVIF and WebP formats provide better compression for faster loading
- SVG logos are scalable without quality loss

### Color Palette (extracted from assets):
- Primary: Dark backgrounds with purple/blue gradients
- Accent: Bright blues and purples
- Text: White/light colors for contrast
- Background patterns: Dotted grids with gradient overlays
